# Belajar Digital Humanities untuk Studi Hadis

Jurnal belajar terbuka: dari nol hingga memetakan jaringan sanad
Hadis 18 al-Arbaʿīn al-Nawawiyyah dengan Python.

## Tujuan
- Menguasai dasar DH: analisis teks, jaringan, dan pemetaan historis
- Membangun dataset sanad Hadis 18 dan memvisualkannya di peta

## Struktur
- data/raw — data asli (tidak diedit)
- data/processed — hasil olahan
- notebooks — eksperimen dan analisis
- posts — draf catatan belajar mingguan
